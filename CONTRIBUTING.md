# Contributing

Thanks for your interest in Luxe Beauty.

## Workflow

1. Fork the repo or create a branch from `main`.
2. Use conventional commits: `feat:`, `fix:`, `chore:`, `docs:`, `refactor:`.
3. Ensure `pnpm lint`, `pnpm typecheck`, and `pnpm test` pass locally.
4. Open a pull request against `main`.

## Branch naming

- `feat/short-description`
- `fix/short-description`
- `chore/short-description`

## Code style

- TypeScript strict mode.
- No `any`.
- Prettier formatting is enforced in CI.
